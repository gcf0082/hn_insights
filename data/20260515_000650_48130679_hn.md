## 1. 总结帖子内容

该项目 "DrCatHicks/learning-opportunities" 是一个专为 Claude Code 设计的技能插件，旨在解决 AI 辅助编程过程中的"被动接受"问题。当开发者在完成关键代码工作（创建文件、架构决策、重构等）后，该技能会主动提供 10-15 分钟的学习机会，帮助用户在实践后巩固知识。

核心技术基于证据学习法（Evidence-Based Learning）：
- **预测练习**：在查看解决方案前先尝试预测
- **检索练习**：主动回忆而非被动阅读
- **间隔重复**：利用遗忘曲线优化记忆

## 3. 关键技术点

**学习科学原理应用：**
- 将认知心理学研究转化为可执行的工作流程
- 在"做"之后立即"学"，利用情境记忆增强效果

**AI 辅助编程的元认知：**
- 不只是让 AI 完成任务，而是利用 AI 促进学习
- 区分"使用 AI"和"通过 AI 学习"

**Skills 实现机制：**
- 基于结构化提示的上下文注入
- 与 Claude Code 工作流的事件驱动集成
