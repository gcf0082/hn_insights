## 内容概述

**Pu.sh** 是一个仅用约400行Shell脚本编写的完整编码代理（coding-agent）工具。

## 核心特点

1. **极简设计**：无需npm、pip或Docker，仅依赖curl、awk和一个API密钥即可运行
2. **便携性**：代码量仅约400行，小巧到可以放入口袋
3. **易用性**：通过简单的curl命令即可快速部署使用

## 使用方法

```bash
curl -sL pu.dev/pu.sh -o pu.sh && chmod +x pu.sh
./pu.sh
```

## 总结

Pu.sh 是一个创新性的轻量级编码代理工具，它证明了无需复杂的依赖和框架，仅用基础的Shell脚本和基本的Unix工具就能构建功能完整的AI编程助手。对于追求极简和便携性的开发者来说，这是一个值得关注的开源项目。
