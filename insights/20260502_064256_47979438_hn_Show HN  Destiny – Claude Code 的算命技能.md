## 项目简介

Destiny 是 Claude Code 的插件，提供真正的东方占卜服务。输入生日后，随时输入 /destiny 即可查看今日运势。

### 技术特点

1. **数据层**：使用 Python 脚本计算八字、今日干支、六爻和五行关系，同一人+同一日=相同结果
2. **文本层**：由 Claude 根据数百年传统占卜 convention 生成运势解读，非 LLM 幻觉

### 功能

- 输入生日一次，永久使用
- 支持 /destiny compat <对方生日> <城市> <m|f> 兼容模式
- 可选 SessionStart 时自动运行
