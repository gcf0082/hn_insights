# Kepler: 为金融服务构建可验证的 AI 系统

## 基本信息

- **来源**: [How Kepler built verifiable AI for financial services with Claude](https://claude.com/blog/how-kepler-built-verifiable-ai-for-financial-services-with-claude)
- **发布平台**: Anthropic Claude Blog
- **发布日期**: 2026年4月30日
- **行业**: 金融服务 / AI
- **产品**: Claude Platform

## 公司概况

**Kepler** 成立于2025年，由 Vinoo Ganesh（CEO）和 John McRaven（CTO）联合创立。创始团队曾在 Palantir 负责为国防、能源和金融公司构建数据系统。

- **数据规模**: 索引超过2600万份SEC文件、5000万份公共文档、100万份私人文档，覆盖14000多家公司和27个全球市场
- **技术栈**: AWS, Rust, Python, 容器编排
- **认证**: SOC 2 Type II 已完成，ISO 27001 认证进行中

## 核心问题

金融服务行业在严格监管环境下运营，每份监管文件、交易方案或研究报告中的数据都必须可验证。传统工具可以拉取数据，但仍然需要分析师进行验证。AI 系统虽然可以解释问题并进行计算，但过程与结果混合在一起，难以追溯。

正如一位董事总经理所说："我怎么可能信任一个无法审计的东西？"

## 解决方案

Kepler 构建了确定性基础设施作为 AI 的信任和验证层，结合 Claude 作为推理和解释层，推出 **Kepler Finance**：一款金融服务研究平台，允许分析师用英语提问并获得即时可验证的答案。

### 关键设计决策

1. **多阶段管道架构**
   - Opus 4.7: 复杂推理，如意图分解、消除歧义、生成结构化执行计划
   - Sonnet 4.6: 高吞吐量、受限任务

2. **专业训练模型**
   - 一些使用 Claude 作为基础，另一部分专属于 Kepler
   - 在财务标签映射到标准化分类代码的任务中达到94%准确率，而其他模型仅为38-46%

3. **确定性执行环境**
   - Claude 可以调用执行环境进行必须可证明正确的操作
   - 开发了专有本体，将财务概念映射到精确的定义和公式

4. **上下文工程**
   - 给 Claude 精确定义的任务，增强结构化领域知识
   - 定义硬边界：什么可以解决，什么需要上报

## 验证不确定性处理

在基准测试中，Kepler 发现：
- 简单查询：所有前沿模型表现相当
- 长链多步骤计划：到第4或5步时，除 Claude 外所有模型开始走捷径或丢失约束

**关键差异**：大多数模型在遇到歧义时选择一个含义并继续，而 Claude 会停下来询问分析师决定。Ganesh 指出："这种行为比任何基准分数都重要。金融分析早期的一个错误假设会破坏下游所有内容。"

## 可验证性特性

- **全文溯源**: 检索层从验证的SEC文件中拉取数据，计算结果，组装成 Excel 模板，一键追溯每个数字到源文件中确切的高亮行项目
- **审计日志**: 从第一天起构建完整的审计日志、隔离客户环境和端到端溯源
- **安全性**: 每一步都执行安全和访问控制限制

## 架构优势

Claude 的推理与 Kepler 的确定性基础设施分离，使小团队能够快速构建：
- 新功能几周内即可完成，而大型团队需要数月
- 架构是模块化的：改进一个阶段的推理无需触及管道的其余部分

## 最佳实践

1. **给 Claude 合适的任务**
   - 检索是查询引擎的工作
   - 计算是公式引擎的工作
   - 让 Claude 解释、分解或推理

2. **模型与阶段匹配**
   - Opus 用于复杂推理
   - Sonnet 用于受限、高吞吐量任务

3. **投资评估先于提示**
   - 构建自动化管道，在每个阶段测试 Claude 的输出与已知正确答案
   - 金融领域，静默回归可能导致永久失去客户

4. **从第一天就为溯源而构建**
   - 专业人士习惯验证一切
   - 溯源必须塑造整个系统，而不是最后添加

## 应用扩展

Kepler 的平台按设计是领域无关的。从金融服务开始是因为它是对 AI 要求最苛刻的环境之一：密集的数据、过载的术语、复杂的计算、零容忍错误。这种经过验证的架构适用于需要从大型文档集合中获得可验证答案的任何场景，如医疗保健提供商对照治疗方案协调临床试验数据、法律团队追溯几十年判例法中的先例。
