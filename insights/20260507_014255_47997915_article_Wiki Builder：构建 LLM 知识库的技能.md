## 摘要

Wiki Builder 是一个开源的 Claude Code 插件，用于快速构建 LLM 知识库。它将手动构建知识库的工作流程自动化，通过一行命令即可创建完整的文件夹结构、配置文件和提示模板。该插件支持多种知识库类型（research、paper、domain、product、person、organization、project），每个知识库拥有独立的配置文件以适应不同场景。

## 核心功能

1. **一键初始化**: 安装后只需一句指令即可创建新知识库，自动生成文件夹布局、配置文件和提示模板
2. **可配置的知识库类型**: 支持7种不同风格，每种风格有不同的文件夹结构和模板
3. **本地配置驱动**: 每个知识库包含 `wiki.config.md`，定义目的、受众、页面类型和更新规则
4. **维护循环**: 支持编译页面、归档答案、检查结构（查找薄弱页面、缺失反向链接）

## 技术实现

插件包含三个核心组件：

1. **脚手架脚本** (`init_wiki.sh`): 创建文件夹结构、渲染模板、复制提示文件，默认写入 `~/dair-wikis/<slug>`
2. **提示模板**: 可重用的提示用于编译索引、编译源页面、编译概念页面、查询和归档答案、清理知识库
3. **SKILL.md**: 教会 Claude 何时使用插件、如何读取本地配置、质量标准（每个声明必须追溯到来源）

## 文件夹结构

```
wiki/
├── wiki.config.md        # 知识库配置
├── raw/                  # 原始素材
├── wiki/                 # 编译后的页面
│   └── index.md
├── derived/              # 派生数据
├── prompts/              # 提示模板
│   ├── compile-index.md
│   ├── compile-source-page.md
│   ├── compile-concept-page.md
│   ├── query-and-file.md
│   └── lint-wiki.md
├── logs/
│   └── maintenance-log.md
└── sources.md            # 来源列表
```

## 安装方式

```bash
/plugin marketplace add dair-ai/dair-academy-plugins
/plugin install wiki-builder@dair-academy-plugins
```

或手动运行脚本：

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/wiki-builder/scripts/init_wiki.sh" agent-memory --title "Agent Memory" --flavor research
```

## 实际案例

作者使用 Wiki Builder 创建了 Agentic Engineering Wiki，包含：
- 51条可操作技巧（7个类别）
- 9家公司简介（Anthropic、OpenAI、Google DeepMind等）
- 10篇论文摘要
- 14个开源工具条目
- 社区精选和时间线

所有声明都链接回来源，猜测内容有明确标记。

## 与传统方案对比

与传统使用嵌入向量、向量数据库和检索管道的知识库方案不同，Wiki Builder 采用结构化 Markdown 知识库的方式，适合中小规模（几十篇论文、几家公司、若干 HN 讨论）的场景。优势在于工作流程持久化，每个有用的答案都有固定归宿，知识库可以积累，未来查询成本更低。
