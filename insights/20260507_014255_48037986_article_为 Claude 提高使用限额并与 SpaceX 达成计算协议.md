# Anthropic 与 SpaceX 合作：Claude 使用限制大幅提升

**发布日期**：2026年5月6日  
**洞察链接**：https://www.anthropic.com/news/higher-limits-spacex  
**来源**：Anthropic 官方新闻

---

## 核心摘要

Anthropic 宣布与 SpaceX 达成重大合作伙伴关系，这将显著提升其计算能力。结合近期其他计算资源合作，Anthropic 能够大幅提升 Claude Code 和 Claude API 的使用限制。

---

## 一、使用限制提升

### 1.1 Claude Code 五小时速率限制翻倍

适用于 Pro、Max、Team 和基于席位的 Enterprise 计划。

### 1.2 移除峰值时段限制

取消 Claude Code 在高峰时段的限制降幅，适用于 Pro 和 Max 账户。

### 1.3 API 速率限制大幅提升

大幅提升 Claude Opus 模型的 API 速率限制。

---

## 二、SpaceX 计算合作

### 2.1 合作协议

Anthropic 与 SpaceX 签署协议，使用其 Colossus 1 数据中心的全部计算能力：

- **新增容量**：超过 300 兆瓦
- **GPU 数量**：超过 220,000 个 NVIDIA GPU
- **上线时间**：本月内

该容量将直接改善 Claude Pro 和 Claude Max 订阅者的使用体验。

### 2.2 轨道计算兴趣

作为协议的一部分，Anthropic 还表达了与 SpaceX 合作开发数吉瓦级轨道 AI 计算能力的兴趣。

---

## 三、其他计算合作伙伴

### 3.1 Amazon

- 最高 5 吉瓦 (GW) 协议
- 2026 年底前新增近 1 GW 容量

### 3.2 Google 和 Broadcom

- 5 GW 协议
- 2027 年开始逐步上线

### 3.3 Microsoft 和 NVIDIA

- 战略合作伙伴关系
- 包含 300 亿美元的 Azure 容量

### 3.4 Fluidstack

- 500 亿美元美国 AI 基础设施投资

---

## 四、国际扩展

Anthropic 计划扩展国际计算能力，以满足受监管行业（金融、医疗、政府）的合规和数据驻留要求：

- 亚洲和欧洲的额外推理能力（通过与 Amazon 的合作）
- 优先选择法律和监管框架支持此类投资的民主国家
- 确保供应链安全（硬件、网络、设施）

---

## 五、电费承诺

Anthropic 曾承诺覆盖美国数据中心导致的消费者电费上涨，并探索将这一承诺扩展到新管辖区的方法。

---

## 六、硬件多样性

Anthropic 在多种 AI 硬件上训练和运行 Claude：

- AWS Trainium
- Google TPU
- NVIDIA GPU
