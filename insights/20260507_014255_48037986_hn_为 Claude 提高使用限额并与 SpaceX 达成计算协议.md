## 内容摘要

Anthropic 宣布与 SpaceX 达成重要合作伙伴关系，将大幅提升其计算能力。此次合作内容包括：

### 1. 提高使用限额

- **Claude Code 限制提升**: 将 Pro、Max、Team 和企业计划用户的五小时 rate limits 加倍
- **取消峰值时段限制**: 移除 Pro 和 Max 账户在高峰时段的限制
- **API 限额提升**: 大幅提高 Claude Opus 模型的 API rate limits

### 2. SpaceX 计算合作

Anthropic 与 SpaceX 签署协议，使用 SpaceX Colossus 1 数据中心的全部计算容量，获得超过 300 兆瓦的新增容量（约 22 万个 NVIDIA GPU），将在一个月内投入使用。

### 3. 其他计算合作

- 与 Amazon 达成高达 5 吉瓦 (GW) 协议，2026 年底前提供近 1 GW 新增容量
- 与 Google 和 Broadcom 达成 5 GW 协议，2027 年开始上线
- 与 Microsoft 和 NVIDIA 的战略合作，包含 300 亿美元 Azure 容量
- 与 Fluidstack 在美国 AI 基础设施投资 50 亿美元

### 4. 国际扩张

Anthropic 计划在亚洲和欧洲增加推理能力，以满足金融、医疗和政府等受监管行业的合规和数据驻留要求。同时承诺覆盖美国数据中心导致的消费者电价上涨，并探索将这一承诺扩展到新地区。
