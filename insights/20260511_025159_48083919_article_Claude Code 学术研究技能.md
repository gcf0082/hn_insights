## 项目概述

Academic Research Skills (ARS) 是一套完整的 Claude Code 学术研究技能包，涵盖从研究到论文出版的全流程。该项目旨在为学术研究者提供 AI 协作工具，帮助完成文献检索、论文撰写、同行评审等学术工作任务。

核心理念：**AI 是副驾驶，不是机长**。该工具不会替用户写论文，而是处理搜文献、排格式、验数据、查逻辑一致性等苦工，让研究者专注于定义问题、选择方法、诠释数据意义等需要人类智慧的任务。

## 核心功能模块

### 1. Deep Research (深度研究)
- **版本**: v2.8
- **模式数**: 7 种 (full, quick, socratic, review, lit-review, fact-check, systematic-review)
- **功能**: 13 个 Agent 组成的研究团队，支持苏格拉底引导、PRISMA 系统性回顾、意图表检测、对话健康度监控、跨模型验证、Semantic Scholar API 验证

### 2. Academic Paper (学术论文撰写)
- **版本**: v3.0
- **模式数**: 10 种 (full, plan, outline-only, revision, revision-coach, abstract-only, lit-review, format-convert, citation-check, disclosure)
- **功能**: 12 个 Agent 的论文撰写 pipeline，含风格校准、写作质量检查、LaTeX 强化、可视化、修订教练、引用格式转换、反泄漏协议、VLM 图表验证

### 3. Academic Paper Reviewer (论文审査)
- **版本**: v1.8
- **模式数**: 6 种 (full, re-review, quick, methodology-focus, guided, calibration)
- **功能**: 7 个 Agent 的多视角同行评审，0-100 质量量表 (主編 + 3 位动态审查者 + 魔鬼代言人)，含让步门监协议、攻击强度保持、R&R 追溯矩阵

### 4. Academic Pipeline (全流程调度器)
- **版本**: v3.7
- **功能**: 10 阶段 orchestrator，含自适应 checkpoint、声称验证、素材护照、可选 repro_lock、跨模型诚信验证、中途强化机制、分数轨迹追踪

## 架构设计亮点

### 10 阶段 Pipeline
1. RESEARCH → 2. WRITE → 2.5 INTEGRITY → 3. REVIEW → 3→4 Revision Coaching → 4. REVISE → 3' RE-REVIEW → 4'. RE-REVISE → 4.5 FINAL INTEGRITY → 5. FINALIZE → 6. PROCESS SUMMARY

### 诚信门监 (Integrity Gates)
- **Stage 2.5**: 7 模式 AI 失败检查清单 (实现错误、幻觉引用、幻觉实验结果、捷径依赖、方法论伪造、框架锁定)
- **Stage 4.5**: 零容忍深度检查，确认无回归

### 数据访问层级 (v3.3.2+)
- `raw`: 原始数据，任取可能被对抗
- `redacted`: 脱敏材料
- `verified_only`: 仅在上游诚信门监后运行

### 协作深度观察员 (v3.5.0)
- 纯观察建议，永不阻流程
- 从 4 维度评估人机协作模式：委托强度、认知警觉、认知重新配置、区域分类
- Mandator门监 (2.5/4.5) 明确跳过观察员

## 评估与洞察

### 优势
1. **完整的工作流**: 从研究到出版的全流程覆盖
2. **人机协作模式**: 强调 AI 为辅、人为主的理念
3. **多层次质量保证**: 7 模式诚信检查、协作观察员
4. **灵活的部署方式**: 支持插件和传统 symlink 两种安装
5. **活跃的社区**: 5.6k 星标，持续更新

### 潜在挑战
1. 学习曲线较陡，需要熟悉 Claude Code 和学术研究流程
2. 某些功能需要额外配置 (Pandoc、tectonic 等)
3. 跨模型验证等功能需要额外成本
4. 部分功能仍处于实验阶段 (v3.6.x)

### 适用人群
- 学术研究者 (研究生、博士生、科研人员)
- 需要 AI 辅助进行学术写作的用户
- 对学术论文规范和流程不熟悉的新手
- 希望提高研究效率的资深研究者
