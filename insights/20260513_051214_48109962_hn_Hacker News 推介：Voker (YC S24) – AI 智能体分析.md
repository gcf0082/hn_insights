## 项目简介

Voker.ai 是 YC S24 孵化的 AI Agent 分析平台，由 Alex 和 Tyler 联合创立。该平台为 AI 产品团队提供全面的 Agent 性能洞察，帮助团队了解用户向 Agent 提出了哪些需求，以及 Agent 是否成功满足了这些需求。

## 核心产品

Voker 提供一个轻量级 SDK，支持 OpenAI、Anthropic 和 Gemini，采用 LLM 栈无关的设计，专门为 Agent 产品构建。该 SDK 可以自动标注对话，识别用户意图（Intents）、修正（Corrections）和解决（Resolutions），并通过层级文本分类生成动态分类，为团队提供更高层次的洞察。

## 解决的问题

- **缺乏可见性**: Agent 工程师和 AI 产品团队对生产环境中 Agent 的性能缺乏足够的洞察
- **被动发现问题**: 90% 的 YC 创始人表示，他们主要通过客户投诉来发现 Agent 失败
- **调试效率低**: 工程师需要花费数百小时手动检查日志来发现和调试问题

## 与现有方案的区别

- **vs Langfuse**: Voker 专注于产品和业务层面的洞察（如用户未预期的意图），而 Langfuse 更侧重于工程师的技术调试
- **vs Amplitude**: Amplitude 的 AI Analyst 是在其传统产品分析基础上叠加 LLM 助手，而 Voker 是专门为 Agent 数据设计的分析平台
- **vs 手动 LLM 分析**: 不使用 LLM 进行核心数据工程，确保分析结果的一致性、可重复性和准确性

## 定价

- 免费版：每月 2,000 事件
- 付费版：$80/月起，30 天免费试用

## 社区反馈摘要

1. **与 Langfuse 的区别**: 创始人回应称 Voker 与 Langfuse 互补，前者面向整个产品团队，后者专注于工程师
2. **关于 PM 经验**: 有评论质疑创始人的 PM 经验，以及仅依赖 LLM 猜测分类的有效性。创始人回应拥有丰富的 PM、ML 工程和数据科学经验
3. **与 Amplitude 的比较**: 创始人表示 Amplitude 更关注 trace 细节，而 Voker 更注重语义数据处理和自动标注
4. **数据模型问题**: 讨论了如何比较不同工具/策略的 Agent，创始人表示关注用户结果而非原始 token/turn 指标
5. **定价门槛**: 有评论指出 1,000+ 会话/月的门槛对初创公司来说偏高，创始人表示会继续优化定价策略
