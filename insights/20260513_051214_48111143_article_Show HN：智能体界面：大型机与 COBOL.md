# Hopper — 首个 mainframe 智能开发环境

**洞察链接**: https://www.hypercubic.ai/hopper

**发布公司**: Hypercubic

**产品类型**: AI 智能体开发环境（针对 mainframe/z/OS）

---

## 产品概述

Hopper 是 Hypercubic 公司推出的首个面向大型机（mainframe）的智能体开发环境。该产品将人工智能代理与传统的 TN3270 终端相结合，为开发者提供了一个现代化的方式来操作 z/OS 系统。

## 核心功能

### 1. AI 智能体驱动 ISPF

Hopper 的 AI 代理能够：
- 通过面板 ID 驱动 ISPF
- 编写符合列要求的 JCL（作业控制语言）
- 将 spool 失败解码为结构化诊断信息
- 使用 SQL 查询 VSAM 数据集

### 2. 编译、测试、部署一体化

用户可以通过单一提示完成以下操作：
- 驱动 JCL 执行
- 解析 JES 返回码
- 将程序 NEWCOPY 到 CICS
- 在每次更改前暂停等待用户批准

### 3. 智能作业调试

通过 @-tag 功能快速诊断失败的作业：
- 解码 JESMSGLG、JESYSMSG 和 SYSUDUMP
- 提取 abend 代码、失败步骤和源代码行号
- 无需在 SDSF 中手动搜索

### 4. 完整的 TN3270 终端

保留传统终端的所有功能：
- 完整的 PF、PA 和注意键支持
- 与传统 TN3270 使用体验一致
