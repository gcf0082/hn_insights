## 政策背景与影响分析

### 1. 积分池分离

从2026年6月15日起，订阅用户的交互式使用（如 Web 端的 Claude.ai 对话）和编程式使用（如 Agent SDK、Claude Code、第三方工具）将使用独立的积分池。在此之前，编程工具曾享受订阅积分的补贴，这意味着用户实际获得的编程能力远超其订阅费用所对应的价值。

### 2. 用户反应

这一变化引发了社区的广泛讨论。部分开发者认为这是"倒退"而非"福利"，因为：

- **积分消耗速度加快**：取消补贴后，编程工具的积分消耗速度显著提升
- **成本增加**：积分用尽后，用户需按标准 API 费率付费
- **历史争议**：此前曾出现用户因第三方工具误判被收取 $200.98 费用的事件

### 3. Anthropic 的意图

Anthropic 表示此举措旨在更清晰地界定不同使用场景的计费方式，避免意外账单。但社区普遍认为这是公司将此前"隐藏成本"显性化的策略。

## 总结

Anthropic 正在逐步将编程工具的使用从订阅补贴中分离出来。这一变化意味着依赖 Claude Agent SDK、Claude Code 或第三方工具的开发者将面临更高的使用成本。对于需要大量编程能力的用户，建议提前评估并规划预算。
