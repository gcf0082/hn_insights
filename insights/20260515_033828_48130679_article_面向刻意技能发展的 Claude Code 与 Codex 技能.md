## 项目概述

Learning Opportunities 是一个 Claude Code 和 Codex 技能（skill），专注于在 AI 辅助编码过程中进行刻意技能培养。该项目采用自适应"动态教科书"方法，帮助用户在完成架构工作（新文件、模式变更、重构）后，整合基于科学的学习练习。

## 核心功能

### 1. 学习练习机制
当用户完成重要工作后，Claude 会询问："你想做一个关于 [主题] 的快速学习练习吗？大约 10-15 分钟。"练习类型包括：
- **预测 → 观察 → 反思**：你期望发生什么？现在看看。什么让你惊讶？
- **生成 → 对比**：在查看实现之前，先构思你的方法
- **追踪路径**：逐步执行，预测每个转换
- **调试**：这里会出什么错？为什么？
- **教学**：像迎新开发者一样解释这个组件
- **检索检查**：这次开始时，你记得上次的内容吗？

### 2. 刻意学习设计
项目基于五个学习科学原理：
1. **生成效应**：接受生成的代码而减少自己生成代码会跳过建立理解所需的主动处理
2. **流畅性错觉**：生成的干净代码可能被视为比实际理解的更易懂
3. **间隔效应**：机器速度可能使用户倾向于持续突击和长时间生产会话
4. **元认知**：快速工作流程往往没有空间监控学习和发展
5. **测试与检索**：Agentic 模型推动给出完整答案，减少自我测试机会

### 3. 仓库定向功能（Orient）
可选的 orient 技能帮助用户创建 `orientation.md` 文件，包含针对新仓库的建议课程。该方法应用了程序理解和代码库导航的经验研究策略。

## 团队实验度量

项目提供 MEASURE-THIS.md 配套 playbook，包含：
- 来自开发者繁荣和 AI 技能威胁研究的验证调查项目
- 如何处理结果的指导
- "团队夸耀"模板，用于向领导层展示实验

## 背景研究

该项目基于学习科学，并通过对软件专业人员的多项定性访谈了解他们在 Agentic 编码方面的担忧。研究发现，对学习的强烈价值观和承诺可以预测开发者在适应 Agentic 编码时感到更少的威胁、担忧和焦虑。

## 关键特性

- **动态触发条件**：完成新文件、数据库模式变更、架构决策或重构后触发
- **抑制条件**：会话中已拒绝练习或已完成 2 次练习后将不再提示
- **自定义选项**：可调整触发条件、练习上限、领域特定问题等
- **配套技能**：可与 Learning-Goal 技能配合使用，进行互动式学习目标设定
