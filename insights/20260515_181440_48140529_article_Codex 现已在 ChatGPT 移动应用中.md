# Codex 移动端发布：随时随地编程

## 基本信息

- **洞察链接**: https://openai.com/index/work-with-codex-from-anywhere/
- **标题**: Work with Codex from anywhere
- **作者**: OpenAI
- **发布日期**: 2026年5月14日

## 概述

OpenAI 宣布 Codex 正式登陆移动端，用户可以通过 ChatGPT 移动应用在手机上使用 Codex。目前已有超过 400 万人每周使用 Codex，这次更新让用户能够在任何地方保持与正在进行的编码工作的连接。

## 移动端功能详解

### 实时连接

用户可以将手机连接到任何运行 Codex 的机器（包括笔记本电脑、专用 Mac mini 或托管远程环境）。手机端会加载该环境的实时状态，用户可以：

- 跨所有线程工作
- 审查输出
- 批准命令
- 切换模型
- 启动新任务

用户的文件、凭据、权限和本地设置都保留在运行 Codex 的机器上，而更新（包括截图、终端输出、差异、测试结果和审批）会实时同步到手机。

### 安全架构

Codex 使用安全的 relay 层，让受信任的机器在设备之间可达，无需将机器直接暴露在公共互联网上。该 relay 还能在任何登录了 ChatGPT 的设备上同步活跃会话状态和上下文。

## 实际使用场景

### 1. 等待咖啡时调查 bug

Codex 在开发环境中运行，可以开始检查相关文件、在浏览器中重现问题、运行测试并开始修复。如果 Codex 需要澄清或继续的许可，用户可以在手机上回答或批准。

### 2. 通勤途中做决策

用户可以在离开前让 Codex 承担一个需要时间处理的 refactor 任务，预期到办公室后查看结果。通勤中途，Codex 找到两种可行方案，需要用户指示方向。用户可以在手机上审查权衡，选择路径，到达办公室时任务已按用户想要的方向推进。

### 3. 客户会议前快速准备

用户从连续会议中出来，发现支持问题在 Slack、邮件、文档和基于浏览器的工具之间演化，客户电话即将到来。用户可以让 Codex 综合最新更新，标记关键开放问题，准备简洁的简报。如果新细节到来，可以在加入会议前让 Codex 刷新摘要。

### 4. 及时将新想法转化为行动

无论是在午餐、散步，还是听到引发思考的内容，用户都可以通过手机启动新线程或添加到活跃工作中，让任务在回到办公桌之前开始成形。

## 企业功能更新

### Remote SSH（正式发布）

Codex 可以直接连接到托管远程环境。桌面应用自动检测 SSH 配置中的主机，让用户像在本地一样创建项目和在线程中运行。

### 程序化访问令牌

提供作用域凭据，可直接从 ChatGPT 工作区设置颁发，用于 CI 管道、发布工作流和内部自动化。

### Hooks（正式发布）

可用于扫描提示中的 secrets、运行验证器、记录对话、创建记忆，或为特定存储库和目录自定义 Codex 行为。

### HIPAA 合规支持

支持 ChatGPT Enterprise 工作区在本地环境（CLI、IDE、App）中使用 Codex 进行 HIPAA 合规使用，使医疗组织能够更快、更自信地支持患者护理和运营工作流。

## 可用性

- Codex 在 ChatGPT 移动应用中以预览版推出，iOS 和 Android 均可使用，覆盖所有计划（包括 Free 和 Go）
- Remote SSH 和 Hooks 在所有计划中可用
- 程序化访问令牌适用于 Enterprise 和 Business 计划
- HIPAA 合规使用仅适用于符合条件的 ChatGPT Enterprise 工作区，且仅在本地环境中使用 Codex 时支持
- 连接手机到 Windows 上的 Codex 应用的支持即将推出
