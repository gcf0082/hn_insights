## 基本信息

relaxAI 是一个提供 AI API 服务的平台，其文档涵盖了从入门到高级使用的完整指南。平台提供多种官方 SDK（Python、TypeScript、Go），同时与 OpenAI API 保持 1:1 兼容，方便开发者快速迁移和集成。

## 主要功能模块

### 1. 入门指南 (Getting Started)
- **简介 (Introduction)**: 平台概述和 SDK 安装指南
- **模型与定价 (Models and Pricing)**: 提供的 AI 模型及相关价格信息
- **身份验证 (Authentication)**: API 认证方式和安全配置
- **发起请求 (Making Requests)**: API 调用示例和最佳实践

### 2. 管理功能 (Administration)
- **账户管理**: 用户账户设置和管理
- **安全设置**: 密码更新、双因素认证 (2FA)、会话管理
- **组织管理**: 团队和组织架构配置
- **对话管理**: 会话记录和历史管理
- **API 密钥管理**: 创建、查看使用情况、删除 API 密钥

### 3. API 端点 (Endpoints)

#### 聊天 (Chat)
- **Chat Completions**: 对话补全接口

#### 深度研究 (Deep Research)
- **Create Deep Research**: 深度研究任务创建

#### 模型 (Models)
- **List Models**: 列出可用模型
- **Retrieve Models**: 获取特定模型信息

#### Anthropic
- **Create Messages Beta**: Anthropic 消息创建接口

#### 嵌入 (Embeddings)
- **Create Embeddings**: 文本嵌入向量生成

#### 工具 (Tools)
- **Code Execution**: 代码执行功能

### 4. 集成 (Integrations)

#### 代理 AI 平台
支持与 Dify、FlowiseAI、LangChain、Langflow、LlamaIndex、N8N、OpenHands、Qodo、Semantic Kernel 等平台集成。

#### 对话式 AI
支持 ChatbotKit、GPT4All、Jan.ai、Rasa、Shapes Inc、SillyTavern 等对话框架。

#### 开发者生产力工具
支持 Aider、Cline、Claude Code、Claude VSCode、Forge Code、Graphiti、Hyprnote、Kilo Code、MindsDB、NL2SH、Roo Code、Sourcegraph Cody 等开发工具。

#### AI 开发环境
支持 Continue.dev、Replit、Void、Zed 等在线开发环境。

## SDK 安装

### 官方 relaxAI SDK

```bash
# Python
pip install relaxai

# Node.js
npm install relaxai

# Go
go get -u 'github.com/relax-ai/go-sdk@latest'
```

### 使用 OpenAI SDK

```bash
# Python
pip install openai

# Node.js
npm install openai
```

## 技术特点

1. **多语言 SDK 支持**: 提供 Python、TypeScript、Go 三种语言的官方 SDK
2. **OpenAI 兼容**: 与 OpenAI API 1:1 兼容，可直接使用 OpenAI 官方库
3. **RESTful API**: 基于 REST 架构的 API 设计
4. **丰富的集成选项**: 支持多种主流 AI 平台和开发工具的集成
5. **完善的安全机制**: 支持双因素认证、API 密钥管理、会话管理等安全功能

## 总结

relaxAI 是一个功能完善的 AI API 平台，提供了从基础聊天到深度研究的多种能力。其与 OpenAI 的兼容性使得现有项目可以轻松迁移，同时丰富的集成选项和详细的文档使其成为开发者构建 AI 应用的良好选择。
