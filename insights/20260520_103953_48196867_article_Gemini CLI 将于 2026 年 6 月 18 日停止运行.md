# 洞察报告：Gemini CLI 转型为 Antigravity CLI

## 基本信息

- **链接**: https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/
- **发布日期**: 2026年5月19日
- **作者**: Dmitry Lyalin (集团产品经理), Taylor Mullen (首席工程师)
- **来源**: Google Developers Blog

## 内容摘要

Google 宣布将其 Gemini CLI 过渡到 Antigravity CLI，这是一个重要的产品转型。Gemini CLI 去年推出时，旨在将 Gemini 的能力直接带入终端。在过去一年中，Google 收到了来自数百万用户的反馈，获得了超过 10 万 GitHub 星标、6000 个合并的 Pull Request 以及数百位贡献者的支持。

### 转型原因

用户的 workflow 需求已经发生了变化：现在需要多个 agent 相互协作来分解工作并解决复杂问题。这意味着终端工具需要与整个 workflow 共享统一的后端。

为了更好地满足用户需求，Google 决定将资源集中投入到 Google Antigravity 这一面向 agent 的开发平台。该平台包含强大的服务端架构和全新的终端体验——Antigravity CLI。

### 保留的核心功能

虽然不会立即实现 1:1 的功能完全对等，但 Antigravity CLI 保留了 Gemini CLI 最关键的功能：
- **Agent Skills**: Agent 技能
- **Hooks**: 钩子
- **Subagents**: 子代理
- **Extensions** (现为 Antigravity 插件)

### 新功能改进

1. **更快的执行速度**: 使用 Go 语言构建，响应更灵敏
2. **异步工作流**: 可在后台编排多个 agent 执行复杂任务，支持大规模重构或同时研究多个主题
3. **统一架构**: 与 Antigravity 2.0（桌面应用）共享相同的 agent 框架，确保核心 agent 的改进自动应用到所有使用场景

## 重要时间线

### 个人用户

- **2026年5月19日**: Antigravity CLI 现已开放给所有人下载
- **2026年6月18日**: Gemini CLI 和 Gemini Code Assist IDE 扩展将停止为 Google AI Pro 和 Ultra 用户服务，同时也停止为免费使用的 Gemini Code Assist 个人版用户服务

### 企业用户

如果组织通过 Gemini Code Assist Standard 或 Enterprise 许可证使用 Gemini CLI 或 IDE 扩展，或者通过 Google Cloud 使用 Gemini Code Assist for GitHub，您的访问权限保持不变。Google 将继续支持 Gemini CLI 和 Gemini Code Assist，并提供最新的 Gemini 模型更新。Gemini CLI 仍可通过付费的 Gemini 和 Gemini Enterprise Agent Platform API 密钥访问。

## 结论

Google 正在通过 Antigravity CLI 和 Antigravity 2.0 为开发者提供更强大的 agent-first 开发平台。这一转型反映了 AI 开发工具从单一 CLI 向多 agent 协作平台的演进趋势。
