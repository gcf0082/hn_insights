## 项目概述

`remove-ai-watermarks` 是一个用于从AI生成的图像中移除可见和不可见水印的工具。支持移除 Google Gemini（Nano Banana）、ChatGPT/DALL-E、Stable Diffusion、Adobe Firefly、Midjourney 等模型生成图像中的水印。

该工具可以剥离 SynthID、C2PA Content Credentials、EXIF/XMP "Made with AI" 标签，以及可见的闪光覆盖层。

## 核心功能

### 1. 可见水印移除
- 移除 Gemini / Nano Banana 的闪光logo
- 通过反向alpha混合技术实现（快速、离线、确定性）
- 速度：约0.05秒/图像，无需GPU

### 2. 不可见水印移除
- 移除 SynthID、StableSignature、TreeRing 等
- 基于扩散的再生技术
- 默认使用 SDXL 管道（原生长约1024像素）
- 2026年5月更新：SDXL 管道可击败 Gemini 3 Pro 输出的 SynthID v2

### 3. AI元数据剥离
- 移除 EXIF 标签（prompt、seed、model hash等）
- 移除 XMP DigitalSourceType（用于Instagram、Facebook、X显示"AI生成"标签）
- 移除 PNG 文本块、 C2PA 溯源清单

### 4. 模拟人类化
- 胶片颗粒和色差注入
- 绕过AI图像分类器

### 5. 智能人脸保护
- 自动检测并提取人脸
- 扩散后用柔和椭圆掩码将原面部混合回去
- 防止AI扭曲面部特征

### 6. 批量处理
- 支持整个目录的批量处理

## 支持的AI模型

| AI模型 | 可见水印 | 不可见水印 | 元数据 |
|--------|---------|-----------|--------|
| Google Gemini / Nano Banana | ✅ | ✅ SynthID v1+v2 | ✅ C2PA + EXIF |
| OpenAI DALL-E 3 / ChatGPT | — | — | ✅ C2PA manifest |
| OpenAI ChatGPT Images 2.0 | — | ⚠️ 不可感知像素水印 | ✅ C2PA manifest |
| Stable Diffusion | — | ✅ DWT/隐写术 | ✅ PNG text chunks |
| Adobe Firefly | — | — | ✅ Content Credentials |
| Midjourney | — | — | ✅ EXIF + XMP |

## 技术原理

### Gemini/Nano Banana 可见水印移除
Google Gemini 在图像上使用alpha混合添加可见闪光logo：
```
watermarked = α × logo + (1 − α) × original
```

通过已知alpha图反向计算：
```
original = (watermarked − α × logo) / (1 − α)
```

使用三阶段NCC（归一化互相关）检测器动态找到水印位置和缩放。

### SynthID等不可见水印移除
移除管道（默认SDXL配置）：
```
图像 → 调整到~1024px → 编码到潜在空间(VAE)
→ 添加受控噪声（前向扩散）
→ 去噪（反向扩散，约50步，强度0.05）
→ 解码回像素(VAE) → 上采样到原始分辨率
```

## 安装使用

```bash
# 使用 pipx 安装
pipx install git+https://github.com/wiltodelta/remove-ai-watermarks.git

# 或使用 uv
uv tool install git+https://github.com/wiltodelta/remove-ai-watermarks.git
```

CLI 使用：
```bash
# 移除所有水印（可见+不可见+元数据）
remove-ai-watermarks all image.png -o clean.png

# 批量处理
remove-ai-watermarks batch ./images/ --mode all
```

### 威胁模型
该工具针对已分发的AI图像，抵御自动检测系统（社交平台"AI生成"标签、第三方分类器）。它不会匿名化生成过程。

特别指出：移除水印不会消除Google服务器端的记录。如果原始水印文件经过提示来源控制的系统，Google仍可链接到生成账户。

## 使用场景

**适合**：
- 自己生成的图像，想作为自己的作品发布
- 安全/鲁棒性评估
- 艺术或历史记录保护

**不适合**：
- 期望移除水印后对Google匿名（不可能）
- 分发AI生成内容并声称人类创作

## 技术要求

- Python ≥ 3.10
- 可见水印移除/元数据：仅CPU，无需GPU
- 不可见水印移除：推荐GPU（CUDA或MPS），CPU也可（较慢）
