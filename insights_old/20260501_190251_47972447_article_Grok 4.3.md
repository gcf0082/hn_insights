## 模型概述

Grok 4.3 是 xAI 开发的最新旗舰模型，于 2026年4月17日发布。该模型具有行业最低的幻觉率，响应速度快，推理能力强。Grok 4.3 与 OpenAI 和 Anthropic 的 SDK 完全兼容，迁移非常简单，只需生成 API 密钥并更改 URL 即可。

## 核心特性

### 1. 自动推理能力
Grok 4.3 具有自动推理能力，无需配置 `reasoning_effort` 参数。模型会自动进行推理，返回精准、可信赖的响应。这与 `grok-4.20-multi-agent` 不同，后者通过 `reasoning.effort` 参数控制代理数量。

### 2. 推理内容摘要
Grok 4.3 暴露了模型内部推理的摘要内容，支持与流式响应一起流式传输推理摘要。开发者可以在流式传输过程中实时获取模型的内部推理过程。

### 3. 工具调用能力
具备智能工具调用能力，支持多代理协作处理复杂任务。

### 4. API 兼容性
- 与 OpenAI SDK 完全兼容
- 与 Anthropic SDK 兼容
- 基础 URL: `https://api.x.ai`
- 认证方式: `Authorization: Bearer` 头

## API 端点

### 聊天完成 API
```
POST https://api.x.ai/v1/chat/completions
```

### 响应 API
```
POST https://api.x.ai/v1/responses
```

## 使用示例

### Python 示例
```python
from xAI import Client
import os

client = Client(
    api_key=os.getenv("XAI_API_KEY"),
    timeout=3600,
)

chat = client.chat.create(
    model="grok-4.3",
    messages=[system("You are a highly intelligent AI assistant.")],
)

chat.append(user("What is 101*3?"))
```

### cURL 示例
```bash
curl https://api.x.ai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $XAI_API_KEY" \
  -m 3600 \
  -d '{
    "input": [
      {"role": "system", "content": "You are a highly intelligent AI assistant."},
      {"role": "user", "content": "What is 101*3?"}
    ],
    "model": "grok-4.3",
    "stream": false
  }'
```

## 定价信息

Grok 4.3 是付费模型，具体定价可在 xAI 官方定价页面查看。模型支持 OpenAI 兼容格式的令牌计费。

## Grok 4.3 Beta 新增功能（2026年4月）

### 1. 文档生成
支持原生文档生成能力，可以直接通过对话生成 PDF、电子表格和 PowerPoint 幻灯片。

### 2. 视频理解
支持对话式视频理解，可以分析视频内容并回答相关问题。

### 3. 语音 API
- **语音转文本 (STT)**: 支持批量转录和实时流式转录，定价比 OpenAI 低 86%
- **文本转语音 (TTS)**: 支持多种语音和语言，定价比 OpenAI 低 86%，比 ElevenLabs 低 92%

### 语音 API 端点
- 批量转录 (REST): `POST https://api.x.ai/v1/stt`
- 实时转录 (WSS): `wss://api.x.ai/v1/stt`
- 语音合成: `POST https://api.x.ai/v1/tts`
