## Adam Fusion 扩展安装指南

### 基本信息

Adam Fusion 是 Autodesk Fusion 360 的 AI 助手扩展，可通过智能体原生驱动 CAD 设计。

### 安装方式

#### 一键安装（推荐）

约10秒完成：

- **macOS**: 在终端中运行 `curl -sSL https://fusion.adam.new/install.sh | bash`
- **Windows**: 在 PowerShell 中运行 `irm https://fusion.adam.new/install.ps1 | iex`

安装程序会将扩展程序放入 Fusion 的标准 AddIns 文件夹。安装完成后需退出 Fusion 并重新打开，然后在 Fusion 中按 `Shift+S` → Add-Ins 选项卡 → 找到 AdamFusion → 点击 Run 并勾选 Run on Startup。新插件默认禁用，需点击一次 Run 后才会自动加载。

#### 手动安装

1. 下载 AdamFusion.bundle.zip 并解压
2. 将 Contents 文件夹移入 Fusion 的 AddIns 文件夹：
   - macOS: `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/`，重命名为 AdamFusion
   - Windows: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\AdamFusion`
3. 强制退出并重新打开 Fusion 360
4. 按 `Shift+S` 打开 Add-Ins 面板，找到 AdamFusion，点击 Run 并勾选 Run on Startup
5. 在右侧面板登录 Autodesk 账户即可开始使用

### 系统要求

支持 macOS 和 Windows 版本的 Autodesk Fusion 360。提供免费套餐，无需信用卡。
