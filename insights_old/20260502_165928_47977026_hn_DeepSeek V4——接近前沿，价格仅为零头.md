## 核心内容

中国 AI 实验室 DeepSeek 近日发布了备受期待的 V4 系列模型，包括两个预览版本：DeepSeek-V4-Pro 和 DeepSeek-V4-Flash。这两个模型都支持 100 万 token 上下文的混合专家（Mixture of Experts）架构。

### 技术规格

- **Pro 版本**: 总参数 1.6T，活跃参数 49B，在 Hugging Face 上占用 865GB
- **Flash 版本**: 总参数 284B，活跃参数 13B，占用 160GB
- **许可证**: 标准 MIT 许可证
- **模型规模**: DeepSeek-V4-Pro 是目前最大的开源权重模型，超过 Kimi K2.6（1.1T）和 GLM-5.1（754B）

### 定价优势

| 模型 | 输入价格（$/M token） | 输出价格（$/M token） |
|------|---------------------|---------------------|
| DeepSeek V4 Flash | $0.14 | $0.28 |
| GPT-5.4 Nano | $0.20 | $1.25 |
| DeepSeek V4 Pro | $1.74 | $3.48 |
| Claude Opus 4.7 | $5 | $25 |
| GPT-5.5 | $5 | $30 |

DeepSeek-V4-Flash 是最便宜的小模型，比 OpenAI 的 GPT-5.4 Nano 更便宜。DeepSeek-V4-Pro 则是最便宜的前沿大模型。

### 效率提升

根据 DeepSeek 论文，在 100 万 token 上下文场景下：
- V4-Pro 仅需 V3.2 单 token FLOPs 的 27%，KV cache 仅需 10%
- V4-Flash 更进一步，仅需 V3.2 单 token FLOPs 的 10%，KV cache 仅需 7%

## 社区观点

### 积极评价

- **成本优势明显**: 有用户实际测试后报告，在 Pro 版本上完成一个 TypeScript 代码库的深入分析（包括 API、DTOs、服务层、数据库模型），仅花费 $0.09，而使用 Claude Opus 可能需要 $9-$13
- **性能接近前沿**: 多位用户表示 V4 Pro 的质量与 OpenAI 5.4 或 Claude Opus 4.6 相当
- **价格仍然有竞争力**: 即使不考虑 75% 折扣（截至 2026/5/31），DeepSeek 仍然比竞品便宜很多

### 担忧与讨论

- **数据隐私问题**: 有评论指出人们对中国模型的数据安全问题关注较少，相比之下 GitHub 自动使用用户代码训练模型会引发大量抗议。有用户回应"因为他们免费提供且价格可接受"
- **折扣后的价格**: 有人指出当前价格是 75% 折扣后的结果，折扣期结束后价格可能上涨
- **本地运行期待**: 用户期待量化版本的 Flash 模型能够在本地机器上运行

### 技术细节

- AWS Bedrock 有 DeepSeek 模型托管，但最新版本是 8 个月前的 v3.1
- 有用户提到可以结合 opencode Go + pi.dev 使用 DeepSeek v4 Pro
- 有人观察到模型在推理过程中会显示大量"实际上不"、"等一下"、"这没道理"等思考过程

## 结论

DeepSeek V4 系列代表了开源大模型的重要突破——以显著更低的价格提供了接近前沿水平的性能。1.6T 参数的 Pro 版本仅需 $1.74/M 输入 token，是 Claude Opus 4.7 的三分之一价格。社区对实际使用效果普遍给予正面评价，但也关注数据隐私和折扣期后的价格变化。随着量化版本的发布，DeepSeek V4 Flash 可能在本地运行方面带来更多可能性。
