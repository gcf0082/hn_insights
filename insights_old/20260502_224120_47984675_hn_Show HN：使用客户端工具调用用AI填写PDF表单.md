## 项目简介

SimplePDF Copilot 是一个基于 AI 的 PDF 编辑器助手，可以在浏览器端执行以下操作：

- 填写表单字段
- 回答问题
- 聚焦特定字段
- 添加/删除页面

### 技术特点

1. **隐私优先**：PDF 文件永远不会离开浏览器，所有解析、渲染和字段检测都在客户端完成
2. **客户端工具调用**：通过 iframe postMessage 在浏览器端执行工具调用，而非服务器端
3. **支持本地模型**：可使用 LM Studio 等本地模型，无需数据外传
4. **技术栈**：Tanstack Start + Vercel AI SDK + Tailwind

### 与传统"Chat with PDF"的区别

传统工具只能检索文本/OCR 层，而 Copilot 可以直接操作 PDF：填写字段、添加字段、删除页面等。

## 社区讨论要点

### 1. 隐私安全问题
- 用户指出聊天消息会发送到远程服务器，任何 PII 数据都会离开本地机器
- 作者已更新提示文案，明确说明"您的聊天消息会离开您的设备"

### 2. 表单填写准确性
- 用户测试中发现 SSN 被填写到错误的字段（4 Exemptions）
- 用户反映部分必填字段无法跳过或留空
- 作者演示了通过对话让 LLM 跳过字段的方法

### 3. 与 Claude Code 对比
- 有用户询问该工具与 Claude Code 的区别

### 4. 功能限制
- 目前支持 AcroForms，但不支持 XFA 表单（政府表单常用格式）

### 5. 潜在应用场景
- 填写外语表单
- 签署合同前审查条款
- 从现有数据源（CRM, EHR）预填表单

## 总结

SimplePDF Copilot 展示了一种创新的客户端 AI 交互方式，通过工具调用实现本地执行的隐私保护。核心价值在于：

- 数据无需离开用户设备
- 支持本地大语言模型
- 可直接操作 PDF 而非仅提取文本

评论集中在隐私说明的清晰度以及表单字段处理的准确性问题上。
