## 内容摘要

Google Chrome 在用户不知情的情况下，静默在用户设备上安装了约 4 GB 的 AI 模型。该模型基于 Gemma 3n，通过 Chrome 的 Prompt API 在后台自动下载。用户无法明确控制这一行为，引发了隐私和存储空间方面的担忧。

---

## 主要讨论观点

### 1. 技术细节
- Chrome 148 将于明天发布，届时 Prompt API 将成为桌面版默认行为
- 模型大小：CPU 版本约 2.7 GiB，GPU 版本约 4.0 GiB
- 下载需要设备至少有 22 GiB 空闲磁盘空间
- 用户可通过 `chrome://flags` 中的 `#optimization-guide-on-device-model` 和 `#prompt-api-for-gemini-nano` 标志禁用该功能

### 2. 隐私担忧
- 未经用户同意自动下载AI模型
- 用户难以察觉存储空间被占用
- 技术知识不足的用户很难理解磁盘空间减少的原因

### 3. 替代方案
社区建议的替代浏览器包括：
- **Firefox**：可完全禁用AI功能，提供良好的隐私扩展支持（如 uBlock Origin）
- **LibreWolf**：Firefox 的隐私导向分支
- **Waterfox**：注重隐私的Firefox分支
- **Zen Browser**：基于Firefox的Arc风格浏览器
- **Helium**：去除Google臃肿功能的Chromium分支
- **Ladybird**：全新的开源浏览器项目

### 4. 存储与网络问题
- 对于使用按量计费网络的用户，4GB下载会消耗大量流量
- 在磁盘空间有限的设备上，4GB占用显著
- 部分用户发现Chrome占用了12GB以上的空间用于多个版本的模型

### 5. 环境与资源
- 数百万设备同时下载将产生大规模网络流量
- 本地运行AI模型会增加用户设备的电力消耗

---

## 用户建议

1. 立即访问 `chrome://flags` 禁用相关AI功能
2. 考虑使用 Firefox 或其他隐私导向的浏览器
3. 安装 uBlock Origin 等广告拦截器以改善浏览体验
4. 关注浏览器设置中的 "AI Controls" 选项
