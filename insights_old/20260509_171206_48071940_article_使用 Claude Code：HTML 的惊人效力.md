## 核心观点

Anthropic 工程师 Thariq Shihipar 认为，在 AI 辅助编程时代，HTML 相比 Markdown 具有显著优势，已成为其主要输出格式。

## 主要内容

### 1. 为什么选择 HTML？

- **信息密度更高**：支持表格、CSS 样式、SVG 图形、代码片段、动态交互、流程图等复杂内容呈现
- **视觉更清晰**：通过选项卡、插图、链接等元素组织内容，支持移动端自适应
- **易于分享**：可上传到云端生成链接，同事可随时查看
- **双向交互**：可添加滑块、按钮等控件，实现参数微调和即时反馈
- **数据摄取能力强**：Claude Code 可遍历本地文件、接入 MCP 获取 Slack、Linear 等工具的数据

### 2. 适用场景

- **需求与计划**：生成多方案对比、详细实施计划、界面草图
- **代码审查**：渲染代码差异、注释、流程图，比 GitHub 视图更好用
- **设计与原型**：快速制作交互原型，支持参数调试
- **报告与研究**：整合多源数据生成精美报告，自动绘制 SVG 图表
- **自定义编辑器**：快速构建临时可视化编辑器，支持导出功能

### 3. 常见问题

- **Token 消耗**：虽然 HTML 消耗更多 Token，但在 100 万上下文窗口下可忽略
- **版本控制**：HTML 文件差异对比较乱，是最大痛点
- **生成速度**：约为 Markdown 的 2-4 倍，但结果物超所值

## 总结

HTML 让人机协作更具参与感，作者已几乎完全放弃 Markdown，转向 HTML 作为主要输出格式。
