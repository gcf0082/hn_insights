## 核心内容总结

### 一、主要更新概述

Google 在 Gemini API File Search 工具中推出了三项重大更新：

1. **多模态支持**（Multimodal Support）
2. **自定义元数据**（Custom Metadata）
3. **页面级引用**（Page-Level Citations）

### 二、多模态支持

File Search 现在可以同时处理图像和文本数据。基于 **Gemini Embedding 2** 模型，该工具能够理解原生图像数据，为 AI 智能体提供上下文感知能力。

**典型应用场景**：
- 创意机构可通过自然语言描述搜索特定情感风格或视觉风格的图像资产，无需依赖关键词或文件名
- 用户可搜索情感基调、视觉风格等抽象概念

**实际案例**：
- **K-Dense**：AI 联合科学家，自动执行跨科学、工程、医疗和金融的多步骤工作流，构建统一视觉记忆
- **Klipy**：GIF 库搜索，可精确识别图像中的文字内容，提升语义检索质量
- **Code Fundi**：为自主工程提供上下文层，通过多模态搜索索引开源项目的架构图、ERD 和序列图

### 三、自定义元数据过滤

允许开发者为非结构化数据附加键值标签（如 `department: Legal` 或 `status: Final`），在查询时应用元数据过滤器，精确限定数据范围。

**优势**：
- 显著减少无关文档带来的噪音
- 提高 RAG 工作流的速度和准确性

### 四、页面级引用

File Search 现在可将模型响应直接关联到原始来源，自动捕获索引信息的页码。帮助用户直接定位答案出处，提升信任度和事实核查能力。
