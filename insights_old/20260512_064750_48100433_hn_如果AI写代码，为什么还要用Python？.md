## 核心讨论

本帖探讨了 AI 编程时代为何仍要选择 Python，主要观点如下：

### 支持 Python 的理由

1. **生态系统成熟** - AI/ML 库丰富，训练数据充足
2. **代码可读性强** - 接近伪代码，易于理解和审查
3. **调试方便** - 不编译可直接运行和排错
4. **性能瓶颈多在 DB/网络** - Python 速度对于大多数应用足够

### 替代语言的观点

1. **Rust** - 类型安全减少 AI 输出空间，提供内存安全，编译时检查严格
2. **Go** - 语言简洁、标准库丰富、依赖少、适合 vibe coding
3. **强类型语言优势** - 编译器能捕获错误，AI 生成代码质量更高

### 关于语言选择的共识

- 选择你最熟悉的语言
- 语言会影响思维抽象方式（类 Sapir-Whorf 假说）
- 人机协作中人类负责最终验证，代码可调试性很重要
- AI 生成代码仍需人类审查

## 洞察总结

HN 社区普遍认为，AI 辅助编程的语言选择没有绝对答案。关键因素包括：
1. 个人/团队对语言的熟悉程度
2. 项目的具体需求
3. 强类型语言对 AI 代码质量的帮助
4. 调试和代码审查的便利性

最终推荐仍是"用你最熟悉的语言"——因为最终需要人类来验证和调试 AI 生成的代码。
