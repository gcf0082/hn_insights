# 洞察报告

## 基本信息

- **原始链接**: https://martin.sh/i-let-ai-build-a-tool-to-help-me-figure-out-what-was-waking-me-up-at-night/
- **发布日期**: 2026年5月11日
- **作者**: Martin
- **阅读时长**: 9分钟

## 核心洞察

### 问题背景

作者住在嘈杂的城市中，经常在凌晨3点左右醒来，却不知道是什么声音把自己吵醒。由于睡眠时大脑处于从睡眠阶段转换的过程中，很难在醒来时识别是什么噪音。作者希望找到问题的根本原因，而不是盲目猜测解决方案。

### 解决方案概述

作者利用现有的智能家居系统（Home Assistant 和各种传感器），添加了：

1. **两个廉价 USB 麦克风**：一个在室内，一个在窗外面向街道
2. **树莓派**：仅在作者在家、上床睡觉时监听
3. **Garmin 手表**：获取睡眠数据
4. **Web 应用**：整合音频、睡眠数据和传感器事件

### 技术亮点

- 树莓派连续录音到内存缓冲区，仅在检测到超过阈值的音量时才保存音频片段
- 噪音抑制配置文件降低环境噪音基准，减少误报
- 音频片段包含事件前后的上下文
- 睡眠阶段转换和醒来事件会被视觉高亮标记
- 作为渐进式 Web 应用，通过 Web Push 通知用户

### AI 的角色

作者明确表示：**AI 不是用来识别具体声音的**，而是用来降低构建工具本身的成本。整个项目耗时约8小时，没有AI这几乎不可能实现。

AI 辅助的具体方式：
- 让 AI agent 直接 SSH 到树莓派进行测试
- 测试时让 AI 喊叫、扔东西、开水龙头等，录制样本后分析
- 不阅读代码，只测试结果并提供反馈

### 发现的噪音来源

通过数据分析，识别出主要噪音来源：

1. **门声**：邻居关门或家人去卫生间时关门不够小心
2. **碗碟声**：高频尖锐的声音，意外地能很好地穿透公寓
3. **街道噪音**：摩托车、踏板车、卡车、垃圾车

### 采取的改进措施

- 添加声学面板（IKEA 办公用隔音板效果出乎意料地好）
- 在卧室门和窗户周围增加隔音材料（硅胶、橡胶等）
- 对于部分室内噪音，通过沟通解决

### 关键经验总结

1. **先测量再修复**：没有数据，无法针对性地解决问题或验证效果
2. **上下文比原始数据更重要**：噪音日志本身用处不大，需要结合心率、门是否打开、当时处于哪个睡眠阶段等上下文
3. **选择够用最简单的信号**：Garmin 的睡眠阶段不够精确，但醒来检测足够好，能指向值得倾听的时刻
4. **AI 工具降低了个人工具的门槛**：很多以前觉得"不值得做"的小项目，现在可以轻松花一个周末试试

### 未来可能的扩展

- 仅在有值得查看的内容时通知
- 使用模型将相似音频分组，自动识别声音类型
- 条件警报：仅在可能打扰睡眠时才通知

### 适用场景建议

即使不构建完整系统，只要在床边放置一个麦克风，第二天早上回顾峰值，就能学到很多东西。对于住在嘈杂城市、且睡眠追踪器显示"睡眠质量差"但不知道原因的人，建议尝试某种版本的解决方案。
