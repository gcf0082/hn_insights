## 核心内容

### 产品发布概述

Claude Platform on AWS 现已正式上线，为 AWS 客户提供了一种全新的方式来访问完整的 Claude Platform 功能，包括 AWS 身份验证、计费和承诺消费抵扣。同时，Claude 仍然可以通过 Amazon Bedrock 获取，此时 AWS 作为数据处理器。

### 主要功能特性

Claude Platform on AWS 包含以下原生平台功能：

- **Claude Managed Agents（测试版）**：大规模构建和部署 AI 代理
- **Advisor 策略（测试版）**：通过咨询顾问模型为代理提供智能增强
- **网络搜索和网络获取**：利用来自互联网的最新现实数据增强 Claude 的知识
- **代码执行**：在 API 调用中直接运行 Python 代码、创建可视化和分析数据
- **文件 API（测试版）**：在对话中上传和引用文档
- **技能（测试版）**：教授 Claude 最佳实践，确保交付一致的结果
- **MCP 连接器（测试版）**：无需编写客户端代码即可将 Claude 连接到任何远程 MCP 服务器
- **提示缓存**：降低重复上下文的成本和延迟
- **引用**：在源文档中为响应提供依据
- **批量处理**：用于高容量异步工作负载

### 可用模型

Claude Opus 4.7、Sonnet 4.6 和 Haiku 4.5 均可用，新模型在 Claude Platform on AWS 上与原生 Claude API 同步发布。

### 企业级集成

- 通过 AWS IAM 进行身份验证
- 通过 CloudTrail 进行审计日志记录
- 通过单一 AWS 发票完成计费，可完全抵扣现有承诺
- 客户使用现有 AWS 凭据和 IAM 策略
- 将在大多数 AWS 商业区域可用，支持全球和美国推理区域

## 两种部署方式对比

| 特性 | Claude Platform on AWS | Claude on Amazon Bedrock |
|------|------------------------|--------------------------|
| 运营商 | Anthropic | AWS |
| 数据处理位置 | AWS 边界之外 | AWS 边界之内 |
| 功能更新 | 与原生 API 同一天发布 | 可能延迟 |
| 适用场景 | 追求完整 Claude Platform 体验 | 有严格区域数据驻留要求 |

---

## 战略意义

Claude Platform on AWS 的发布标志着 Anthropic 与 AWS 合作的重要里程碑。这一平台为 AWS 客户提供了更大的灵活性和更完整的功能访问，同时保持了与现有 AWS 基础设施的深度集成。对于已经在使用 AWS 的企业来说，这意味着可以更便捷地将 Claude 的先进 AI 能力融入到现有的云运营模型中。

---

## 总结

Claude Platform on AWS 的推出为 AWS 客户提供了两种访问 Claude 的路径，企业可以根据自身需求选择功能更完整的 Claude Platform 或数据处理更本土化的 Amazon Bedrock。这一发布将进一步推动企业级 AI 应用的普及。
