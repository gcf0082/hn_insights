## 内容摘要

本帖讨论了 Anthropic 公司对 Claude Code 编程使用的新限制政策。用户反馈指出，此次调整导致价格大幅上涨，部分用户面临近 10 倍的费用增长。

## 关键观点

### 价格问题
- 有用户报告称，之前仅使用 40% 配额的订阅用户，现在需要支付约 1000 美元/月的 API 费用
- 此前相同使用量仅需约 100 美元，新定价涨幅达 10 倍
- 用户原本可通过 `claude -p` 在 CI/CD 环境中使用订阅附带的 token，新政策改为提供 $20/$100/$200 的"积分"，用完后需按标准 API 费率计费

### 受影响的工具和服务
- **ACP (Claude Provider)**: 用于 Zed 编辑器的第三方工具，将受到新政策影响
- **Conductor**: 使用 SDK 的工具，用户考虑切换到 Codex
- 所有使用 Claude Agent SDK 的第三方应用均受影响

### 用户态度
- 许多用户对价格上涨表示不满，开始考虑转向竞争对手
- 有用户认为 Anthropic 此举是在针对程序员群体，而程序员本应是其主要客户
- 部分用户将此视为"Anthropic 的质量下降"(enshittification)

### 争议点
- 交互式使用 `claude -p` 被归类为编程工具而非对话式使用，用户需打开全屏界面才能避免被计为编程工具
- 有用户质疑是否真的需要 AI 来处理电子邮件和语音邮件回复

## 总结

Claude Code 的新定价政策引发了用户的强烈不满，尤其是依赖编程工具进行自动化任务的用户面临显著的成本上升。随着用户对竞争对手（如 Codex）的关注增加，Anthropic 可能面临用户流失的风险。
