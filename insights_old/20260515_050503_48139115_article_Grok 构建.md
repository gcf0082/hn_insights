## 产品概述

xAI 正式发布了 Grok Build 和 Grok CLI，这是该公司首次进军代理式编程（Agentic Coding）领域。这两款产品旨在与 Anthropic 的 Claude Code、OpenAI 的 Codex、Google 的 Jules 以及更广泛的 Cursor 和 Copilot 领域展开竞争。

Grok Build 采用双轨产品设计，允许用户通过本地 CLI 代理或 Web 界面运行编程任务。本地执行机制是其最引人关注的特性，而围绕所谓的"Grok Computer"的讨论表明 xAI 可能会同时推出桌面客户端。

## 技术规格

### 模型后端
- **核心模型**：grok-code-fast-1
- **上下文窗口**：256,000 tokens
- **性能表现**：在 SWE-Bench Verified 测试中达到 70.8% 准确率

### 功能特性
- **八个人工智能代理并行工作**：支持多代理协作处理复杂编程任务
- **Arena Mode**：竞技模式，支持代码对比和优化
- **三种工作流程**：Plan（规划）→ Search（搜索）→ Build（构建），端到端执行无需切换工具
- **支持语言**：TypeScript、Python、Java、Rust、C++、Go

### 定价模式
- **API 定价**：按量计费，每百万输入 tokens 3 美元，每百万输出 tokens 15 美元
- **SuperGrok 订阅**：30 美元/月，提供更高配额和 Grok 4 Heavy 访问权限

## 本地优先策略

Grok Build 采用本地优先（Local-First）策略，通过 Electron 桌面应用封装 Web UI，使代理系统能够获得系统级访问权限。这种设计既实现了代码复用，又为用户提供了完整的本地开发环境。

社区还发现了新的连接器层（Connectors Layer），可将 Grok Code 扩展到第三方服务，拓宽了代理的操作范围。

## 与现有 Grok CLI 的关系

值得注意的是，xAI 之前已有社区开发的第三方 Grok CLI 工具，其特点包括：
- 通过 npm 全局安装：`npm install -g @vibe-kit/grok-cli`
- 支持 GROK.md 配置文件自定义项目行为
- 支持 Model Context Protocol（MCP）集成
- 开源可自定义

官方版本的 Grok CLI 预计将在功能上更加完善，并与 Grok 4.3/4.4/4.5 模型系列深度整合。

## 总结

Grok Build 和 Grok CLI 的发布是 xAI 在人工智能编程助手领域的重要布局。凭借 256K 上下文、三阶段工作流程和并行代理架构，Grok Build 为开发者提供了一个有竞争力的选择。其按量计费的定价模式特别适合使用模式多变的开发者，而本地优先的设计则满足了追求终端工作流的用户需求。
