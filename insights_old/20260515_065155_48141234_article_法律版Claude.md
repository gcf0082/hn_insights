## 项目概述

Claude for Legal 是 Anthropic 提供的一套法律工作流程插件，专门针对企业内部商业、隐私、产品、公司、就业、诉讼、监管、AI治理、知识产权以及法律教育领域的工作场景而设计。该项目同时支持作为 Claude Cowork 或 Claude Code 的插件安装，也可通过 Claude Managed Agents API 进行部署。

## 核心功能

### 领域覆盖

该套件涵盖以下法律专业领域：

- **commercial-legal**: 供应商协议审查、NDA处理、SaaS订阅管理、修订追踪、续约提醒、升级路由
- **corporate-legal**: M&A尽职调查、收盘清单、书面同意、实体合规追踪、并购后整合
- **employment-legal**: 入职和离职审查、工人分类、假期追踪、内部调查、政策起草
- **privacy-legal**: DPA审查、DSAR响应、PIA生成、隐私分类、政策监控
- **product-legal**: 产品发布审查、营销声明检查、风险评估
- **regulatory-legal**: 监管动态追踪、政策对比、差距分析、NPRM评论追踪
- **ai-governance-legal**: AI用例分类、AI影响评估、供应商AI审查、AI监管差距检查
- **ip-legal**: 商标审查、FTO分析、C&D起草、DMCA投诉、OSS合规、IP组合追踪
- **litigation-legal**: 诉讼组合管理、案件时间线构建、权利要求图表、证词准备、简报起草
- **legal-clinic**: 诊所设置、学生入门、案件截止日期追踪、备忘录脚手架
- **law-student**: 苏格拉底式问答、案例摘要、IRAC评分、期末考试预测、学习规划

### AI 代理

项目提供超过80个专门的AI代理，包括：

- **Vendor Agreement Reviewer**: 根据 playbook 审查供应商主协议并生成redline备忘录
- **NDA Triager**: 对入站NDA进行绿/黄/红三色分类
- **DSAR Responder**: 在法定时限内起草DSAR确认和实质性响应
- **Termination Reviewer**: 根据特定司法管辖区的风险标志审查拟议的终止
- **Claim Chart Builder**: 逐要素的权利要求图表（专利或民事诉因）
- **Docketer Watcher**: 监控法院案件动态和截止日期

### 部署方式

项目支持三种部署方式：

1. **Claude Cowork**: 通过自定义插件安装
2. **Claude Code**: 通过 `/plugin marketplace add` 命令添加市场并安装插件
3. **Claude Managed Agents**: 通过 API 在自有工作流引擎后方部署

### 连接器

支持与多种法律系统和生产力工具集成：

- **通用生产力**: Slack、Google Drive、Box
- **法律系统**: Ironclad、DocuSign、iManage、Everlaw
- **研究工具**: CourtListener、Trellis、Descrybe、Solve Intelligence、Westlaw（通过CoCounsel）

## 技术特点

- 所有内容均为 Markdown 和 JSON 格式，无需构建步骤
- 每个插件通过 cold-start interview 进行定制，学习用户的 playbook
- 实践配置文件（CLAUDE.md）被每个技能读取，确保输出符合用户风格
- 每个输出的文档均标注为"律师审查草稿"，非法律意见
- 支持 Claude for Microsoft 365，在 Word 中使用追踪更改模式输出

## 社区生态

legal-builder-hub 插件提供社区法律技能的信任层，包括：

- 安全审查（隐藏内容扫描、注入检测）
- 白名单机制（限制性默认）
- 许可证门控（基于部署上下文）
- 定期重新扫描以检测更新后的恶意代码

## 总结

Claude for Legal 是一个全面的 AI 法律助手套件，通过模块化的插件设计覆盖法律工作的各个领域。其强调律师审查的重要性，所有 AI 生成的内容均标注为草稿而非最终法律意见。该项目体现了 AI 辅助法律工作的最新发展趋势，为法律专业人士提供了强大的自动化工具。
