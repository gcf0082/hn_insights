## 项目简介

**whichllm** 是一款命令行工具，旨在帮助用户在本地硬件上找到最适合运行的大语言模型。与传统的"能运行就推荐"工具不同，whichllm 基于真实的基准测试性能对模型进行排名，而不仅仅是看参数数量。

## 核心功能

1. **硬件自动检测** - 支持 NVIDIA、AMD、Apple Silicon、CPU-only 模式
2. **智能排名** - 根据 VRAM 适配、速度和基准质量对模型进行评分
3. **一键运行** - `whichllm run` 可自动下载并启动聊天会话
4. **代码片段** - `whichllm snippet` 打印可运行的 Python 代码
5. **实时数据** - 直接从 HuggingFace 获取模型信息
6. **任务配置** - 支持一般、编码、视觉、数学等用例筛选
7. **GPU 模拟** - 支持模拟任意 GPU 以测试兼容性
8. **硬件规划** - 反向查询：输入模型名称，输出所需 GPU 规格
9. **JSON 输出** - 支持管道操作，便于自动化集成

## 技术特点

### 证据驱动的排名机制

- 整合 LiveBench、Artificial Analysis、Aider、Vision、Chatbot Arena ELO、Open LLM Leaderboard 等多个基准测试
- 采用置信度加权算法，确保评分准确性
- 支持按任务类型筛选模型

### 时效性感知

- 过期 leaderboard 会被降权处理，防止 2024 年模型凭借过时分数超越 2025/2026 年新模型
- 每个排名结果都会显示基准测试快照日期

### 架构感知估算

- VRAM = 模型权重 + GQA KV 缓存 + 激活值 + 框架开销
- 速度基于 GPU 内存带宽和量化效率计算
- MoE 模型区分活跃参数与总参数进行排名

## 使用示例

```bash
# 自动检测硬件并显示最佳模型
whichllm

# 模拟特定 GPU
whichllm --gpu "RTX 4090"

# 运行模型
whichllm run "qwen 2.5 1.5b gguf"

# 输出代码片段
whichllm snippet "qwen 7b"

# 硬件规划
whichllm plan "llama 3 70b"

# JSON 输出
whichllm --json
```

## 评分体系

模型得分（0-100）由以下因素综合决定：

- **基准质量** - 核心因素，合并多个基准测试结果
- **模型大小** - 最高 35 分，使用 log2 缩放
- **量化方式** - 低位量化会获得乘数惩罚
- **证据置信度** - 从 0.55 到 1.0 不等
- **运行时适配** - 完整 GPU/部分卸载/CPU-only 有不同权重
- **速度** - -8 到 +8 分
- **来源可信度** - 官方组织 +5 分，已知重打包者 -5 分
- **热门程度** - 作为平局打破器

## 总结

whichllm 解决了本地 LLM 选择中的一个核心问题：不仅仅是"能运行哪个"，而是"哪个运行得最好"。通过结合真实基准测试、硬件检测和智能排名，它帮助用户在有限的硬件条件下做出更明智的模型选择。
