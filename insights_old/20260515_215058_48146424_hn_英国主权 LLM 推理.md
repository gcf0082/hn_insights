## 项目简介

relax.ai 是英国主权推理服务提供商，由 Civo 云服务分拆而出。该公司提供 OpenAI 兼容的 API 接口，支持最新的开源大语言模型（包括 Kimi K2.6、DeepSeek V4 Pro、Nemotron 3 Super、GPT OSS 120b），运行在英国境内的 NVIDIA Blackwell GPU 上。公司声称相比 OpenAI 可节省高达 80% 的成本，并强调数据全程留在英国境内，满足金融、法律、医疗、国防等受监管行业的数据驻留要求。

## 社区反馈与洞察

### 主要争议点

1. **公司背景透明度不足**：评论者指出 relax.ai 的文档链接直接跳转至文档站点，而非公司官网，缺乏"About"页面说明公司创始人、公司结构、数据中心位置等基本信息。创始人随后回应称公司是 Civo 的分拆公司，成立于 2018 年，创始人为 Mark Boost，总部位于英国，服务器托管在 Civo 的 LON1 数据中心。

2. **"主权"概念遭质疑**：部分评论者认为使用"主权"一词过于夸张，因为所运行的模型来自国外（如 DeepSeek），芯片由英伟达设计制造，电力也有 44% 依赖进口。另有评论者认为"主权推理"仅意味着没有外国政府可以立即切断电源供应，并非完全自主可控。

3. **数据安全隐患**：评论指出 relax.ai 的隐私政策中包含"我们可能与英国以外的第三方共享个人信息"的条款，并质疑美国 CLOUD 法案是否会凌驾于英国数据保护之上。

4. **定价争议**：有评论将 relax.ai 与 Novita 进行详细比较，发现 relax.ai 的实际成本（579.48 英镑）远高于 Novita（178.22 美元），而非宣传中的"便宜 80%"。

5. **品牌命名批评**：评论认为"relax.ai"是糟糕的域名选择，给人感觉像是随意搜索可用域名后选中的名称，缺乏描述性。

### 建设性反馈

- 评论建议公司应在官网显著位置展示与 Companies House 的直接链接，强调其主权属性
- 有评论询问 API 是否支持预付费账户，以及是否可以选择退出训练
- 有人将 relax.ai 与另一家英国公司 LocAI 进行比较，询问差异化定位

## 总结

 relax.ai 作为英国本土的 LLM 推理服务提供商，在 HN 上获得了 93 分的关注度。社区反馈显示，虽然公司已解答部分关于公司背景的问题，但围绕"主权"概念的争议、数据安全承诺的可信度、以及定价的真实性仍有质疑。综合来看，该服务对于有严格数据驻留需求的英国企业具有一定吸引力，但社区建议潜在用户在选择前仔细审查其隐私政策和实际定价。
