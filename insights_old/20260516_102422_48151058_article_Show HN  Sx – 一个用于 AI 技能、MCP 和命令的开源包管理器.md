## 项目概述

sx 是一款专为AI编码助手设计的包管理器，旨在帮助团队共享和管理AI资产，包括技能（Skills）、MCP配置、命令等。该项目解决了AI助手使用过程中知识共享的难题，让团队成员能够继承最佳实践，提升整体开发效率。

## 核心功能

### 1. 团队知识共享
- 将个人发现的AI使用技巧转化为团队资产
- 新开发者可在第一天就继承团队的AI使用规范
- 中央更新机制：修改一次，所有人即可获得更新

### 2. 智能安装范围
支持多种安装目标，实现精细化权限控制：
- `--org`: 组织内所有人（默认）
- `--repo`: 指定仓库
- `--path`: 仓库内特定路径
- `--team`: 团队成员
- `--user`: 个人用户
- `--bot`: 机器人身份

### 3. 多客户端支持
- Claude Code（全功能支持）
- Cline
- Cursor
- GitHub Copilot
- Gemini (CLI/VS Code/JetBrains/Android Studio)
- Codex
- Kiro
- Openclaw
- claude.ai 和 chatgpt.com（通过 skills.new 云中继）

### 4. 多种分发模式
- **本地模式（Personal）**: 跨个人项目共享工具
- **Git仓库模式（Small teams）**: 通过共享Git仓库分发资产
- **Skills.new模式（Large teams）**: 企业级集中管理，包含Web UI、发现、创建、共享和使用分析

## 技术架构

sx 采用 manifest-and-lock 模式（类似npm、cargo、uv）：

1. **Manifest（sx.toml）**: 保险库的权威来源，记录每个管理的资产及其安装范围
2. **Lock文件**: 每用户的解析结果，安装时读取manifest并解析团队和用户范围
3. **审计+使用流**: 记录所有团队/安装变更和使用事件

## 安装方式

```bash
# Homebrew (macOS/Linux)
brew tap sleuth-io/tap
brew install sx

# 或通过shell脚本
curl -fsSL https://raw.githubusercontent.com/sleuth-io/sx/main/install.sh | bash
```

## 快速开始

```bash
# 初始化
sx init

# 添加资产到保险库
sx add /path/to/my-skill

# 安装资产到当前项目
sx install

# 预览（dry-run）
sx install --dry-run
```

## 可构建和共享的资产类型

- **Skills**: 特定任务的定制提示和行为
- **Rules**: 适用于特定文件类型或路径的编码标准和指南
- **Agents**: 具有特定目标的自主AI代理
- **Commands**: 快速操作的斜杠命令
- **Hooks**: 生命周期事件的自动化触发器
- **MCP Servers** (实验性): 外部集成的MCP服务器
- **Plugins**: Claude Code插件包
