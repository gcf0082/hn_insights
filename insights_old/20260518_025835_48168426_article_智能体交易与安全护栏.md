## 项目概述

Shuriken 是一个面向 AI Agent 的交易基础设施平台，支持全天候交易各类资产类别（链上代币、永续合约、现实世界资产、pre-IPO 股权、预测市场等）。该项目为 AI Agent 提供与 Shuriken 平台集成的技能指南，使 Agent 能够安全地执行自主金融交易。

## 核心功能

### 1. 技能库结构

```
shuriken-skills/
├── skills/           # 技能目录，每个技能包含 SKILL.md
├── src/              # Rust crate 源码
├── tests/            # 测试文件
├── .claude-plugin/   # Claude Code 插件
├── .codex-plugin/    # OpenAI Codex 插件
├── .cursor-plugin/   # Cursor 插件
└── .opencode/        # OpenCode 插件
```

### 2. 包含的技能

| 技能名称 | 用途 |
|---------|------|
| `shuriken:api-integration` | 如何集成 Shuriken API 或 SDK |
| `shuriken:agent-keys` | 如何作为 Agent 进行身份认证 |
| `shuriken:scoping` | 如何理解 Agent 密钥权限范围和最小权限原则 |

### 3. 支持的 AI Agent 平台

| 平台 | 安装方式 |
|-----|---------|
| Claude Code | `/plugin marketplace add` + `/plugin install` |
| OpenAI Codex CLI | `codex plugin marketplace add` + `codex plugin install` |
| GitHub Copilot CLI | `copilot plugin marketplace add` + `copilot plugin install` |
| Gemini CLI | `gemini extensions install` |
| Cursor | 从市场安装或手动添加 |
| OpenCode | 修改 opencode.json 配置 |
| 其他 (Cursor规则, Aider, Zed等) | 通过 AGENTS.md 自动检测 |

## 技术架构

### Rust Crate 使用方式

```rust
[dependencies]
shuriken-skills = { git = "https://github.com/ShurikenTrade/shuriken-skills", tag = "v0.1.0" }

use shuriken_skills::{list, get, render_index};

// 列出所有技能
for skill in list() {
    println!("{}: {}", skill.qualified_name(), skill.description);
}

// 获取技能内容
let skill = get("shuriken:api-integration").expect("skill exists");

// 渲染索引用于系统提示词
println!("{}", render_index());
```

## 安全特性

1. **粒度权限控制**: Agent 仅执行用户授权的操作
2. **无需种子短语**: 运行时环境不暴露敏感密钥
3. **最小权限原则**: 通过 `shuriken:scoping` 技能指导合理配置权限范围
